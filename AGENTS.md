# Serena's Garden: notes for coding agents

All the instructions for working on this site live in **`CLAUDE.md`**, in
this folder: the decisions, the files, the design system, the privacy rules
and how to deploy. Read it first, and follow it whichever assistant you are.

It's kept here as a single file so the notes never drift apart. Don't copy
CLAUDE.md into this one; update CLAUDE.md instead.

Local-only notes that must never be committed are in `CLAUDE.local.md`
(gitignored).
